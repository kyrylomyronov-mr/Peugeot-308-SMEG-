# PSA BSI CAN Emulator (SMEG / SMEG+)

Этот проект представляет собой прошивку для микроконтроллера **ESP32** (с CAN-трансивером) для двунаправленной эмуляции сети BSI концерна PSA (Peugeot/Citroën). 

Главная цель эмулятора — обеспечить полноценную и двустороннюю работу магнитол SMEG / SMEG+ при их установке в автомобили со старой или несовместимой электроникой (VAN/старый CAN, например Peugeot 307), а также для запуска магнитолы "на столе".

## 🚀 Основной функционал

### 1. Эмуляция физических кнопок панели (ID `0x122`)
* Позволяет управлять магнитолой через Web-интерфейс (с телефона или ПК) без физических кнопок.
* Поддерживаемые "кнопки": **Settings (Настройки), Maps (Навигация), Radio, Phone, Apps, Trip (Бортовой компьютер), AC (Климат)**.
* Идеально для работы "на столе" или если оригинальная панель автомобиля не поддерживается магнитолой.

### 2. Управление скрытыми функциями SMEG+ (Макросы 1A7)
* Эмулятор умеет отправлять специальные служебные команды (с автоматическим подсчетом счетчика и контрольных сумм XOR), которые закрыты в обычном меню:
    * Смена **языка системы** в один клик.
    * Переключение цветных **Тем оформления** (Themes).
    * Смена **Единиц измерения** (км/мили, °C/°F).
    * Активация **Инженерного меню** (Engineering Menu) кнопкой с телефона.

### 3. Полноценная эмуляция Времени и Даты (ID `0x276` и `0x39B`)
* Эмулятор работает как "мастер-часы" по стандарту BSI PSA.
* **Синхронизация с ПК:** Установка текущего времени на экране магнитолы одной кнопкой `Синхр. время (с ПК)` из Web-интерфейса.
* Поддержка изменения формата (12 часов / 24 часа).
* 🔄 **Двусторонняя синхронизация:** Если водитель меняет время пальцем на сенсорном экране SMEG (при этом магнитола шлет пакет `0x39B`), эмулятор перехватывает его, меняет свое внутреннее время и начинает транслировать уже новые значения в BSI-пакете. 

### 4. Конфигурация Автомобиля и Язык BSI (ID `0x260` и `0x15B`)
* Эмулятор транслирует базовую конфигурацию блоков (Парктроники, ESP, руль, метрическая система) в пакете `0x260`, заставляя SMEG доверять системе.
* Задает основной язык отображения для меню магнитолы и приборной панели.
* 🔄 **Двусторонняя синхронизация:** Если водитель заходит в настройки автомобиля на экране SMEG (например, меняет галочку дневных ходовых огней или язык), магнитола шлет ответный пакет `0x15B`. Эмулятор "слушает" эфир, перезаписывает собственный массив BSI и моментально выдает в сеть обновленную конфигурацию. Настройки больше не "слетают"!

### 5. Разблокировка закрытых меню (Меню "Автомобиль") (ID `0x361`)
* Эмулятор "агрессивно" транслирует пакет параметров `0x361` вместе с оригинальным BSI автомобиля.
* Это принудительно сообщает магнитоле SMEG о том, что в машине "есть" богатая комплектация, разблокируя для пользователя меню *"Настройки систем автомобиля"* (Адаптивный свет, Помощь при парковке и т.д.).

### 6. Считывание Телеметрии в реальном времени
* Эмулятор перехватывает статусы систем автомобиля и выводит их в Web-интерфейс в режиме цифровой панели:
    * **Напряжение аккумулятора (АКБ)** (из пакета `0x0E6` в Вольтах).
    * **Температура Охлаждающей жидкости (ОЖ)** (из пакета `0x0F6` в °C).
    * **Статус зажигания** (включено/выключено) (из пакета `0x128`).
    * **Статус работы CAN-модуля** (Количество кадров, ошибки приема/передачи, Bus-Off).

### 7. Энергосбережение (Deep/Light Sleep)
* Эмулятор постоянно слушает CAN-шину.
* Как только шина "засыпает" (вы выключили зажигание и закрыли машину, прекратился обмен пакетами), ESP32 자동으로 강제 종료 **уходит в спящий режим** (Light Sleep). Это предотвращает разряд аккумулятора в режиме простоя.
* При появлении первого же пакета в CAN-шине (открытие двери), ESP32 мгновенно просыпается и возобновляет эмуляцию.

### 8. Обновления "по воздуху" (OTA)
* Забудьте про USB-кабель. Извлекать плату из недр торпедо автомобиля больше не придется.
* Полная поддержка прошивки ArduinoOTA — новые версии кода (или исправления конфигураций CAN) можно заливать в эмулятор по Wi-Fi прямо с телефона.
